# Starfruit Orbit — studio site

Public landing, playable web demo (`play/`), privacy, and support for
[clarkestudios.com/starfruit-orbit-site/](https://clarkestudios.com/starfruit-orbit-site/).

Game source lives in the monorepo:
`projects/tiltopia/ideas/starfruit-orbit`.

## Refresh the demo

From the monorepo Starfruit folder:

```bash
npx vite build --base /starfruit-orbit-site/play/
# copy dist/* into this repo's play/
```
